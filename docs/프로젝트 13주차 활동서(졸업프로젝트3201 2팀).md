## 4. 세부 내용

### 4.1 작성 배경

멘토링에서 각 파트별로 어떤 데이터가 전달되는지를 명세한 설계 문서를 작성하라는 피드백을 받았음. 12주차에 작성한 `FINGERING_DESIGN_SPEC.md`는 01_Fingering 모듈의 내부 설계를 다루었으나, 파트 간 인터페이스는 별도로 정리되지 않았음. 이에 전체 파이프라인(01_Fingering → 02_IK → 03_Skinning → 04_Main)의 데이터 흐름을 명세하는 문서를 신규 작성하였음.

### 4.2 Interface A: 01_Fingering → 02_IK

운지법 엔진이 출력하는 JSON의 스키마, 각 필드의 IK 활용 목적, pitch → 건반 3D 좌표 변환 규칙, finger 번호 → UE5 본 이름 매핑, 타이밍 동기화 프로토콜을 명세하였음.

**JSON 주요 필드 및 IK 활용:**

| 필드 | IK에서의 역할 |
|------|--------------|
| `pitch` | 흰건/흑건 구분 후 X·Y 좌표 산출, Z는 `key_depth`로 결정 |
| `finger` | End Effector 본 선택 (1=`thumb_03`, 2=`index_03`, … 5=`pinky_03`) |
| `start_ms` / `duration_ms` | 건반 누름 시작·해제 타임라인 트리거 |
| `wrist_yaw_deg` / `wrist_roll_deg` | `hand_r/l` 본 초기 자세 가이드 |
| `key_depth` | Fingertip Z축 오프셋 = `key_depth × MAX_KEY_TRAVEL` |

**pitch → 3D 좌표 변환 규칙 요약:**
- 흰건: 해당 음계의 누적 흰건 인덱스 × 2.3 cm = X 좌표
- 흑건: 인접 두 흰건 X 좌표의 평균, Y +3.0 cm (뒤쪽)
- Z = `-(key_depth × MAX_KEY_TRAVEL)`

**타이밍 동기화:**
- `t = start_ms`: Fingertip이 Target Position 도달 완료 (건반 눌림)
- `t = start_ms + duration_ms`: Fingertip Z → 0 복귀 (건반 해제)

### 4.3 Interface B: 02_IK → 03_Skinning

IK 솔버가 30fps 기준 프레임마다 출력하는 Joint Transform 시퀀스 구조, UE5 MetaHuman 실제 본 이름, 다중 손가락 동시 처리 방식을 명세하였음.

- **전달 포맷**: UE5 AnimSequence (Skeletal Animation Asset)
- **본 계층**: `hand_r/l` → `thumb/index/middle/ring/pinky_01~03_r/l`
- **ROM 제약**: MCP·PIP·DIP·엄지 CMC 등 관절별 굴곡/신전/내외전 한계값 표로 정리, 초과 시 Soft Constraint 패널티 적용
- **화음 처리**: 동일 타임스탬프의 복수 End Effector를 독립 Jacobian으로 계산 후, 손가락 간 충돌 시 MELODY > BASS > INNER 우선순위 적용

### 4.4 Interface C: 03_Skinning → 04_Main

Skinning 모듈이 렌더링 단계로 전달하는 데이터 구성, Tension Value 계산 수식, Vertex Displacement 포맷, Shader 처리 흐름을 명세하였음.

| 데이터 | 형식 | 설명 |
|--------|------|------|
| Skeletal Animation | AnimSequence | IK 결과 Joint Transform 그대로 전달 |
| Vertex Displacement | Per-vertex `(Δx,Δy,Δz)` | PBD 기반 조직 변형 오프셋 (cm) |
| Skin / Normal / Vein Texture | Texture2D | 피부·주름·피하 조직 표현 |
| Tension Value | float per-vertex (0.0~1.0) | `(θ - θ_rest) / θ_max` → Shader Normal 강도 조절 |

### 4.5 미확정 사항 식별

문서화 과정에서 파트 간 합의가 필요한 미확정 사항 4건을 식별하였음.

| # | 항목 | 관련 파트 |
|---|------|----------|
| 1 | pitch → 건반 3D 좌표 변환 테이블 정확한 수치 | 01_Fingering / 02_IK |
| 2 | MAX_KEY_TRAVEL (건반 최대 누름 깊이, cm 단위) | 01_Fingering / 02_IK |
| 3 | PBD Vertex Displacement 전달 방식 (Buffer vs Texture) | 02_IK / 03_Skinning |
| 4 | Tension Value 계산 기준 (관절 각도 → Tension 매핑 함수) | 03_Skinning |

- **미확정 사항 협의**: 식별된 4건의 파트 간 미합의 항목을 팀 내에서 협의하여 인터페이스 명세 확정.
