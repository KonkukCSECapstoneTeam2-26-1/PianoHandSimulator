# 학기말 보고서: DLS 기반 피아노 연주 손 역운동학(IK) 시뮬레이션

## 1. 프로젝트 개요

본 프로젝트는 MIDI 데이터를 기반으로 실제 피아니스트의 정교한 운지법을 재현하는 고정밀 렌더링 시스템의 핵심인 역운동학(IK) 시뮬레이션 파트를 구현한 것입니다. 기존의 단순한 스키닝 방식에서 벗어나, 생리적 제약 범위 내에서 자연스러운 관절 움직임을 생성하기 위해 DLS(Damped Least Squares) 변형이 적용된 Jacobian 기반 IK 솔버를 채택하여 수렴 안정성을 확보했습니다.

## 2. 시스템 입력 및 출력 (Input & Output)

### 2.1. 입력 (Input)

* **MIDI 음표 데이터 (`NoteEvent`):** 시뮬레이션을 구동하는 핵심 트리거 데이터입니다.
* 발생 시간(`time_ms`), 음표 지속 시간(`duration_ms`).


* 건반 피치(`pitch`), 타건 세기(`velocity`).


* 배정된 손(`hand`), 손가락 번호(`finger`).




* **해부학적 관절 한계 (Joint Limits):** IK 연산 시 인체 구조적 제약을 강제하기 위한 파라미터로, 굴곡/신전(Flexion/Extension), 벌림/모음(Abduction/Adduction), 비틀림(Axial Twist)의 최소/최대 라디안 값을 입력받습니다.

### 2.2. 출력 (Output)

* **관절 전역 변환 행렬 (`globalTransform`):** IK 연산 결과로 도출된 각 손가락 4개 마디의 최종 3D 위치 및 회전 정보입니다.
* **렌더링용 정점 데이터 (`Vertex` 버퍼):** Vulkan 그래픽스 파이프라인으로 전달되는 3D 위치(`pos`) 및 색상(`color`) 데이터로, 매 프레임 GPU 버퍼에 매핑되어 시각적으로 출력됩니다.

## 3. 핵심 알고리즘 로직 (Main Logic)

본 시스템의 핵심인 `updateJacobianKinematics` 함수는 타겟 설정부터 FK/IK 연산까지 매 프레임 다음의 로직을 수행합니다.

1. **동적 타겟 추적 (Target Generation):**
* 현재 시간에 활성화된 NoteEvent를 기반으로 목표 건반의 3D 좌표를 산출합니다.
* 단순한 선형 이동이 아닌, 건반을 누르기 전 손목이 들리는 아치형 궤적(Y축 가중치)과 보간(Lerp)을 적용하여 타건의 무게감을 모사합니다.


2. **순운동학 (Forward Kinematics, FK) 연산:**
* 루프가 시작될 때 손목(Root)을 기점으로 각 관절의 지역 좌표(`localPos`)와 현재 각도(`angle`)를 누적 회전·이동시켜 전역 위치(`pos`)를 도출합니다.


3. **가중치 기반 DLS Jacobian 연산 (Weighted Damped Least Squares):**
* 각 관절의 3축(X, Y, Z) 회전 축 벡터와 End-effector(손끝)까지의 거리를 외적(Cross Product)하여 Jacobian 행렬의 열을 구성합니다.
* **특이점 회피:** Damping factor(0.05)를 행렬에 더해 특이점(Singularity) 부근에서 연산이 폭주하는 IK Flip 현상을 방지합니다.
* **소프트 제약 (Soft Constraints):** 관절 각도가 한계치(ROM)에 다가갈수록 페널티를 기하급수적으로 증가시켜 해당 관절의 가중치 역수($W^{-1}$)를 0에 가깝게 만듭니다.


4. **관절 각도 갱신 및 하드 클램프 (Angle Update & Hard Clamp):**
* 산출된 변화량($\Delta \theta$)의 최대 길이를 제한(Max Step)하여 떨림 현상을 막고, 최종 갱신된 각도가 절대적 생리 범위(Joint Limits)를 벗어나지 않도록 하드 클램프(`std::clamp`)를 적용합니다.



## 4. 시스템 명세 (Specification)

### 4.1. 개발 환경

* **그래픽스 API:** Vulkan (GPU 가속 렌더링 및 동적 버퍼 매핑).
* **언어 및 라이브러리:** C++17 이상, GLFW (윈도우 시스템), GLM (수학 및 벡터 연산).

### 4.2. 자료구조 (클래스 구성)

* **`HelloTriangleApplication`:** Vulkan 초기화 및 메인 루프를 관장하는 호스트 클래스입니다.
* **`Finger` & `Joint`:** 양손 총 10개의 손가락을 표현하며, 각 손가락은 4개의 Joint(Root, 마디1, 마디2, 끝점)를 Composition 형태로 포함합니다.

### 4.3. 생리적 ROM 제약 (Range of Motion Constraints)

자연스러운 모션을 위해 손가락 구조별로 다음과 같은 가동 범위를 엄격하게 제한합니다.

* **일반 손가락 (검지~새끼):**
* MCP 관절: 굴곡 0° ~ 90°, 신전 0° ~ 20°, 내외전 ±20°.


* PIP 관절: 굴곡 0° ~ 100°, 신전 0° ~ 10°, 내외전 없음.


* DIP 관절: 굴곡 0° ~ 80°, 신전 0° ~ 5°, 내외전 없음.




* **엄지 손가락:**
* CMC 관절: 굴곡 0° ~ 50°, 신전 0° ~ 50°, 내외전 ±40°, 축회전 0° ~ 15°.


* MCP 관절: 굴곡 0° ~ 60°, 신전 0°, 내외전 없음.


* IP 관절: 굴곡 0° ~ 80°, 신전 0° ~ 5°, 내외전 없음.
