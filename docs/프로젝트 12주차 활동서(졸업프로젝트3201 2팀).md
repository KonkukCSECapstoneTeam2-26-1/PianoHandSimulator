## 4. 세부 내용

### 4.1 작성 배경

11주차까지 V5 엔진의 알고리즘 버그 수정 및 기능 개선이 마무리되었음. 이에 따라 UE5 연동 단계 진입 전, 현재 구현된 엔진의 설계를 공식 문서로 정리하여 팀 내 공유 기반 및 유지보수 기준을 마련하고자 설계 명세서를 작성하였음.

### 4.2 주요 명세 항목

#### (1) 처리 파이프라인 구조도

MIDI 파일 입력부터 JSON 출력까지의 4단계 처리 흐름을 구조도로 명세하였음.

```
MIDI 파일
  → Module 1: MIDI Parser       (트랙 이름 기반 손 분리 / 화음 그룹화 / 성부 태깅)
  → Module 2: Hand Splitter     (스팬 초과 화음 분리 · 수렴 루프)
  → Module 3: DP Solver         (화음 단위 상태 공간 탐색 / 최적 운지 배정)
  → Module 4: Wrist Physics     (Yaw · Roll 계산 및 클램핑)
  → JSON 출력
```

각 모듈의 함수명, 입출력 타입, 부수 효과를 테이블로 명세하였음.

#### (2) DP 상태 공간 수식 정의

기존 구현에서 암묵적으로 다루던 DP 상태 공간과 전이 함수를 수식으로 명시하였음.

- **상태**: 화음 인덱스 `i`에서의 손가락 배정 튜플 `f = (f₁, f₂, ..., fₖ)`
- **전이**: `dp[i][f] = min { dp[i-1][f'] + cost(chord[i-1], f', chord[i], f) }`
- 오른손/왼손의 손가락 번호 오름차순·내림차순 배정 제약을 명시적으로 기술

#### (3) 비용 함수 9항목 수치 명세

`calc_transition_cost()` 내 각 항목의 적용 조건과 수치를 표로 정리하였음.

| 항목 | 수치 |
|------|------|
| SpanPenalty (한계 초과) | +5,000 / 쌍 |
| RoleAffinity (성부 선호) | −12 ~ +20 |
| MelodyContinuity (레가토) | −20 (보상) / +30 (패널티) |
| CrossingPenalty (손가락 교차) | +2,000 |
| SimultaneousConflict (동시 누름) | +2,500 |
| ArpeggioRolling (방향 불일치) | +35 / 동일 손가락 +60 |
| WristMove | 이동량 × 2.0 |
| FingerDifficulty | f=4: +6 / f=5: +3 |
| BlackKeyPenalty | 엄지 흑건: +25 / 새끼 흑건: +10 |

#### (4) 물리 제약 상수 및 Yaw/Roll 계산 수식 정리

손목 Yaw 및 Roll 각도 계산 로직을 코드에서 추출하여 수식으로 형식화하였음.

```
Yaw:  yaw_deg  = clamp( Σ[(note.pitch − avg_pitch) − OFFSET[finger]] × 2.5 × sign, ±35° )
Roll: roll_deg = clamp( roll_score × sign, ±20° )
      (엄지 흑건 시 +12, 새끼 흑건 시 −12)
```

#### (5) 알려진 설계 이슈 도출

문서화 과정에서 현 구현의 설계 이슈 4건을 식별하였음.

| # | 이슈 | 개선 방향 |
|---|------|----------|
| 1 | MelodyContinuity · ArpeggioRolling 이중 적용 | 단음 구간 플래그로 항목 3 비활성화 |
| 2 | 성부 태깅이 화음 단위 최고/최저음에만 의존 | 인접 화음 간 피치 연속성 추적 |
| 3 | Thumb-under 명시적 장려 로직 부재 | 아르페지오 구간 자동 감지 후 보상 추가 |
| 4 | 단일 트랙 MIDI 손 분리가 피치 밀도에만 의존 | 음역 이력 기반 손 추적 보완 |

## 5. 향후 활동

- **설계 이슈 #1 해소**: 단음 연속 구간(아르페지오)에서 MelodyContinuity와 ArpeggioRolling의 이중 패널티 발생 조건을 분리하여 비용 함수 정확도 개선.
- **아르페지오 자동 감지 및 Thumb-under 적용**: 연속 단음 구간을 명시적으로 감지하여 엄지 넘기기(Thumb-under) 고급 운지 기법 적용.
- **UE5 IK 연동 파이프라인 착수**: 설계 명세서에 정리한 JSON 스키마를 기반으로 UE5 DataTable 변환 스크립트 및 MetaHuman IK Control Rig 바인딩 구현.
