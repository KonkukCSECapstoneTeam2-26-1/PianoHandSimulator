# 코드_v6 산출물 보관 (2026-09-29 중간 제출 시점)

이 폴더는 **중간보고서 제출 당시(2026-09-29)의 운지법 결과물**을 보관한다.
생성 코드는 `02_Implementation/01_Fingering/제출_정근녕_중간/코드_v6/` 이다.

## 왜 분리했나

현행 파이프라인의 결과물과 한 폴더에 섞여 있어, UE5 에서 임포트할 때 어느 쪽이
최신인지 구분하기 어려웠다. 파일명도 비슷하다.

| | 보관본 (이 폴더) | 현행 |
|---|---|---|
| JSON | `<곡명>_fingering.json` | `<곡명>_polyphonic_result.json` |
| CSV | `ue5/<곡명>_fingering_datatable.csv` | `../ue5/<곡명>_polyphonic_result_datatable.csv` |

## 이 결과물을 쓰면 안 되는 이유

2026-10-05 ~ 10-18 사이에 수정된 내용이 반영되어 있지 않다.

- **MIDI 템포맵 미적용** — Format 1 에서 템포 트랙이 음표 트랙에 반영되지 않아
  타이밍에 최대 58.7% 오차가 있다 (드뷔시 '달빛' 244초 곡을 387초로 계산)
- **재타격·미종료 음표 유실**
- `duration_ms` 와 `key_hold_ms` 미분리 — 페달을 고려하지 않아 한 손가락이 서로 다른
  건반을 동시에 누르는 운지가 포함되어 있다
- 손 범위 제약을 화음 단위로만 적용 (순간 단위 위반 다수)
- 엄지 넘기기(thumb-under) 미지원

**IK·Skinning 파트는 상위 폴더의 현행 결과물을 쓸 것.**

## 보존하는 이유

제출 기록이므로 사후에 고치지 않는다. 중간보고서에 기재된 수치의 근거가 이 파일들이다.
최종 보고서에는 현행 수치를 써야 한다.
