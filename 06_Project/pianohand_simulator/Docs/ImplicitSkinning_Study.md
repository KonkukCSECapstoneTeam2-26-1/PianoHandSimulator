## 0. 한 줄 요약

**메쉬를 스키닝하지 말고, "뼈마다 하나씩 붙은 부드러운 음함수(implicit) 볼륨"을 스키닝하라.**
메쉬 정점은 LBS/DQS로 대충 옮긴 뒤, 그 볼륨의 "자기 등위면(iso-value)"으로 그라디언트를 따라 되돌아간다.
볼륨은 강체로만 움직이므로 부피가 절대 줄지 않고(LBS 접힘·DQS 부풀기 없음), 두 볼륨이 만나는 곳에는
자동으로 **접촉면**이 생기며, 합성 연산자를 바꾸면 접힘 옆 살이 **말려 올라가는 bulge-in-contact**가 생긴다.

이것이 사용자가 제시한 레퍼런스 프레임(2013 영상의 "Our method" 손)이 보여주는 효과다:
관절 안쪽은 자기교차 없이 접촉선으로 모이고, 그 양옆 살이 부풀며, 손가락 마디는 뼈처럼 단단히 유지된다.

## 1. 왜 기존 방식으로는 안 되는가 (논문의 문제의식)

| 방식 | 관절 안쪽 | 관절 바깥 | 비고 |
|---|---|---|---|
| LBS | 서로 파고듦(자기교차), 부피 소실(candy-wrapper) | 납작 | 가중치 손질 필요 |
| DQS | 부풀어 오름(outgrowth), 여전히 자기교차 | 과도한 둥긂 | 부피 과장 |
| 물리 시뮬 | 정확 | 정확 | 실시간 불가, 셋업 과다 |
| **Implicit skinning** | **접촉면 생성, 자기교차 0** | **뼈처럼 단단** | 가중치에 둔감, 실시간 |

우리 프로젝트의 기존 파이프라인(§1-M)은 변형률 텐서로 1/J 두께 보정을 했지만, 그것은 "이미 파고든
기하"에서 계산한 응력이라 근본적으로 접촉을 못 만들고, 캡슐 접촉 보정은 ligature(끈 자국)처럼 보였다.
Implicit skinning은 접촉을 **기하 자체의 정의(두 볼륨의 합집합)** 로 만들기 때문에 이 문제가 사라진다.

## 2. 프레임워크 개요 (논문 §3, 학위논문 그림 4.1)

전처리 (한 번):
1. **분할**: 정점을 가장 큰 스킨 가중치의 뼈에 배정한다 (논문 4.2: "assign vertices to bones with the largest influence").
2. **재구성**: 뼈 i 의 부분 메쉬 Mᵢ 를 Hermite RBF 로 근사해 스칼라장 fᵢ: ℝ³→[0,1] 을 만든다. 0.5 등위면이 피부.
   fᵢ > 0.5 안쪽, < 0.5 바깥. (§3)
3. **합성**: fᵢ 들을 합성 연산자 g 로 하나의 장 f 로 묶는다. 합집합(max), 또는 gradient-based bulge-in-contact. (§4)
4. **임베딩**: 각 정점 v 의 휴지 자세 등위값 isoᵥ = f(v) 를 저장한다. 메쉬를 0.5 면에 "붙이지" 않고 장 속에
   **묻어 두는** 것이 핵심 — 세부(주름·핏줄·손톱)가 보존된다 (displacement map과 같은 역할).

런타임 (매 프레임):
5. fᵢ 를 뼈 i 와 함께 **강체로** 이동한다 (f 의 모양은 합성으로 자동 갱신).
6. 정점을 DQS/LBS 로 초기 위치로 옮긴다.
7. 각 정점을 ∇f 방향으로 행진시켜 자기 isoᵥ 에 올린다 (Newton). 접촉선에서 멈춘다. 중간중간 접선 완화.
8. 접촉 부근만 국소 Laplacian 으로 다듬는다.

## 3. Hermite RBF 재구성 (학위논문 §3.3, §4.4)

### 3.1 수식

N 개의 (위치 pₖ, 법선 nₖ) 쌍이 주어질 때,

```
d(x) = Σₖ [ αₖ φ(‖x−pₖ‖) + βₖᵀ ∇φ(‖x−pₖ‖) ],   φ(r) = r³       (eq. 4.1)
```

αₖ ∈ ℝ, βₖ ∈ ℝ³ 가 미지수(4N 개). 제약은 **값과 그라디언트** 둘 다:

```
d(pⱼ) = 0,   ∇d(pⱼ) = nⱼ   (j = 1..N)   →   4N × 4N 밀집 선형계, LU 분해
```

φ = r³ 일 때 각 항은 (v = x − pₖ, r = ‖v‖):

```
φ = r³,   ∇φ = 3 r v,   Hess φ = 3 ( v vᵀ / r + r I )
d(x)  = Σₖ αₖ r³ + 3 r (βₖ·v)
∇d(x) = Σₖ 3 r v αₖ + 3 ( v (βₖ·v)/r + r βₖ )
```

왜 Hermite 인가: 값 제약만 쓰는 RBF 는 f ≡ c 라는 자명해를 피하려고 안팎 오프셋 점(c±ε)을 추가해야 하고,
오목부에서 자기교차가 생긴다. 법선 제약이 있으면 오프셋 점이 필요 없고 안정적이다. r³ 가 가우시안/TPS 보다
스키닝에서 더 강건했다고 보고한다 (§3.3.1).

### 3.2 중심점 선택 (§4.4)

- 부분 메쉬 표면에 **Poisson disk 샘플링**, 모델당 뼈마다 **50~100 개**면 충분.
- **클로저 점(closure)**: 뼈 양 끝 관절 j 에서, 뼈 선 위로 거리 sⱼ 떨어진 점을 추가. sⱼ = 관절에서 가장 가까운
  정점까지의 거리. 법선은 뼈 방향 바깥. 이렇게 하면 인접한 두 장의 끝이 **같은 반지름의 구면**으로 닫혀
  관절에서 서로 미끄러지며 틈이나 혹이 생기지 않는다 (그림 4.4 b→e).
- **컬링**: 관절에 너무 가까운 샘플은 제거 — 뼈 양 끝에서 길이의 h = 0.05 안쪽 (eq. 4.2):
  `h < (vₖ−b⁰)ᵀ(b¹−b⁰)/‖b¹−b⁰‖² < 1−h`.

### 3.3 컴팩트 서포트 리매핑 tr (§4.4)

r³ 는 전역 서포트라 컴팩트 서포트용 합성 연산자를 못 쓴다. 그래서 dᵢ 를 [0,1] 로 리매핑:

```
tr(x) = 1                                  x < −r
      = 0                                  x >  r
      = −3/16 (x/r)⁵ + 5/8 (x/r)³ − 15/16 (x/r) + 1/2    그 외
tr(−r)=1, tr(0)=0.5, tr(r)=0, 양끝에서 1·2차 도함수 0 (C²)
fᵢ = tr ∘ dᵢ,   ∇fᵢ = tr'(dᵢ) ∇dᵢ,   tr'(x) = −15/(16r)(x/r)⁴ + 15/(8r)(x/r)² − 15/(16r)
```

r 은 **뼈에서 가장 먼 샘플까지의 거리**로 잡는다: 그러면 fᵢ = 1 은 뼈 위에서만 도달하고 안쪽에서
그라디언트가 0 이 되는 평원이 생기지 않는다.

## 4. 합성 연산자 (§3.4, §4.5)

### 4.1 합집합과 접촉

Ricci 의 max: `f = maxₖ f̃ₖ`. 2013 논문은 이것만으로 접촉을 만든다. 두 장이 같아지는 곳(f₁ = f₂)에
**그라디언트 불연속**이 생기는데, 그 자리가 정확히 접힌 관절 안쪽의 접촉선이다. 추적 알고리즘이 이
불연속을 감지해 정점을 멈춘다 (§5.3).

### 4.2 Gradient-based 연산자 (Gourmel 2013, 학위논문 §3.4.1)

연산자 g_d(f₁, f₂) 는 두 그라디언트 사이 각 **α = ∠(∇f₁, ∇f₂)** 로 제어된다. 컨트롤러 d(α) 가 0 이면 합집합,
1 이면 블렌드/벌지. 기하학적 관찰 하나로 효과가 자동 국소화된다:

- 관절 **등**과 **옆면**: 두 장의 그라디언트가 거의 **평행** (α ≈ 0) → 합집합, 아무 일도 없음.
- 관절 **안쪽 접힘**: α ≈ **관절 굽힘각** → 벌지/접촉.
- α = π: 서로 다른 부위가 닿은 것 (팔–몸통) → 완전 접촉.

### 4.3 Bulge-in-contact (학위논문 §4.5, 그림 4.6b·4.8)

(f₁, f₂) 평면에서 g = 0.5 가 되는 **프로파일 곡선**으로 연산자를 정의한다. 합집합은 축 위의 두 선분
(0,0.5)–(0.5,0.5), (0.5,0.5)–(0.5,0). 벌지 연산자는 축 선분을 큐빅 B-spline 으로 바깥쪽에 휘게 하며,
논문이 손가락에 고정한 제어점은

```
(0, 0.5), (0.15, 0.45), (0.39, 0.40), (0.44, 0.44), (0.5, 0.5)   (+ 대각 대칭)
```

즉 f₂ 가 0.15 일 때 등위면이 f₁ = 0.45 로 0.05 밖으로, f₂ ≈ 0.40 에서 0.11 밖으로 나갔다가 (0.44,0.44) 를
거쳐 모서리 (0.5,0.5) 로 **되돌아온다**. 되돌아오는 이 꺾임 때문에 접촉선(대각선)은 유지되고, 그 **양옆**
(ρ = f_min/f_max 가 1 에 가까운 띠)만 부풀어 오른다 — 접힘을 메우는 web 이 아니라, 접힘 옆에 입술처럼
말려 올라가는 살이다. d_b(α) 는 "낮은 굽힘각부터 시작"하도록 설계 (그림 4.6b).

전체 g 는 ∆²g = 0 (바이하모닉) 을 다음 경계조건으로 풀어 128³ 격자에 저장한다 (§4.5.1):
`g(f₁,0)=f₁, g(0,f₂)=f₂, g(f₁,1)=g(1,f₂)=1`, 프로파일 위에서 g=0.5, 축에서 법선 도함수 0.

합성 트리: 손가락 뼈 쌍은 bulge-in-contact 로 먼저 묶고(트리 아래), 나머지는 contact 연산자로 위에 쌓는다.

## 5. 등위면 추적 (§4.6.2, 2013 논문 §5)

### 5.1 Newton 투영 (eq. 4.5)

```
vᵢ ← vᵢ − σ ( f(vᵢ) − isoᵢ ) ∇f(vᵢ) / ‖∇f(vᵢ)‖²,    σ = 0.35
```

고정 스텝 경사하강보다 빠르고 강건. σ = 0.35 가 속도/정확도 타협점.

### 5.2 접촉에서 정지 (55°)

자기교차를 막으려면 투영이 **접촉면에서 멈춰야** 한다. max 연산자의 경우 접촉면은 그라디언트 불연속이므로,
"연속한 두 반복 사이 그라디언트가 **55° 이상** 회전하면 접촉면을 넘은 것" 으로 보고 정점을 그 자리에 고정.
(2014 에서는 접촉면을 0.5 등위면으로 직접 모델링해 단조성 변화로도 감지 가능.)

### 5.3 접선 완화 (eq. 4.6–4.7)

초기 DQS 위치가 멀면 삼각형이 심하게 왜곡된다. 두 번의 투영마다 한 번씩, 정점을 1-ring 이웃의 **가중
중심**으로 접선 방향으로 끌어당긴다. qᵢⱼ = 이웃을 vᵢ 의 접평면에 투영한 점, Φᵢⱼ = 휴지 자세에서 미리 구한
**mean value coordinates** (vᵢ = Σ Φᵢⱼ qᵢⱼ 이므로 휴지 자세에서는 아무 효과 없음):

```
vᵢ ← (1−µ) vᵢ + µ Σⱼ Φᵢⱼ qᵢⱼ
µ  = max(0, 1 − (|f(vᵢ) − isoᵢ| − 1)⁴)        → 목표 등위면에 가까울수록 완화량이 0 으로 감소
```

### 5.4 국소 Laplacian 평활 (eq. 4.8)

합집합/접촉 연산자는 접촉 영역 경계에 날카로운 꺾임을 남긴다. 접촉에서 멈춘 정점에 βᵢ = 1, 나머지 0 을
주고 메쉬 위로 **확산**시킨 뒤

```
vᵢ ← (1−βᵢ) vᵢ + βᵢ ṽᵢ      (ṽᵢ = 1-ring 중심)
```

를 몇 번 적용. 접촉 밖의 세부는 β = 0 이라 보존된다. 투영이 끝난 뒤에만 수행.

### 5.5 성능 (표 4.1)

손 31,750 정점·21 뼈: HRBF 저장 10.5 MB, 단일 관절 35 fps, 전체 애니메이션 15 fps (GTX 680, 2013).
fᵢ 는 32³, 연산자는 128³ 3D 텍스처로 샘플링. 병목은 투영해야 하는 정점 수.

### 5.6 한계 (§4.6.2.3)

- 초기 해(LBS/DQS)가 **뼈 너머로** 깊게 파고들면 반대편 면으로 투영된다 (그림 4.15). DQS 권장.
- 시간 독립이라 깜빡임 가능 — 메쉬가 조밀하면 실제로는 문제 없음.
- 메쉬가 접촉/벌지 특징을 담을 만큼 조밀해야 한다 (우리 77k 정점 PN 테셀레이션 메쉬가 여기 해당).
- 2014 Elastic 버전: 초기 해 없이 이전 프레임에서 증분 추적, ARAP 기반 접선 에너지(코탄젠트 가중, 회전은
  DQS 로 사전 지정), 150° 까지 안정. 시간 의존이므로 단일 프레임 캡처 파이프라인에는 2013 쪽이 맞다.

### 6.1 전처리 (게임 스레드, 메쉬당 1회, ≈1 s)

| 단계 | 논문 | 구현 |
|---|---|---|
| 분할 | 최대 가중치 | `Dominant[v]`; **손바닥 그룹** = hand + 4 metacarpal 을 한 부위로 (서로 거의 강체), 지골·엄지 중수골은 각자 |
| 샘플링 | Poisson disk 50~100 | farthest-point sampling, 지골 50 / 손바닥 100 (`ImplicitSamplesPerBone`, `ImplicitPalmSamples`) |
| 컬링 | eq. 4.2, h=0.05 | 관절 평면에서 h·뼈길이 안쪽 제거 (손바닥은 2 mm) |
| 클로저 | 관절 ± sⱼ, 법선 = 뼈 방향 | 근위 관절(뼈 원점), 원위 관절(자식 원점). 말단 지골 끝·손목 캡은 메쉬가 닫혀 있어 생략 |
| 피팅 | 4N×4N LU | double 가우스 소거(부분 피벗). 정규화 좌표 u = (x−origin)/s, s = 뼈–최원 샘플 거리 ⇒ tr 의 r = 1 |
| 등위값 | isoᵥ = f(v) | 자기 부위 ∨ 부모 ∨ 자식 장의 max (휴지 자세에선 d(α)=0 → 합집합) |
| 완화용 | MVC | 1-ring 을 삼각형 방향으로 순환 정렬, 접평면 투영 후 MVC; 열린 링(경계·UV 심)은 균등 가중 |

### 6.2 런타임 패스 (RDG, DeformCS 직후·변형률 패스 이전)

```
DeformCS (LBS/DQS)
└ ImplicitProjectCS  ×⌈N/2⌉ : 정점당 Newton 2 스텝, σ, 허용오차, 55° 정지, 스텝 상한(0.3 cm)
   └ ImplicitRelaxCS        : 스냅샷을 읽어 MVC 중심으로 접선 완화 (µ = 1−(|f−iso|−1)⁴)
└ ImplicitBetaCS ×(k+1)      : 정지 정점 β=1 시드 → 이웃 평균 확산
└ ImplicitSmoothCS ×m        : v ← (1−β)v + β·centroid
└ Normal 재계산 (detail 패스가 꺼져 있을 때도)
TensionAccumulate … (이후 기존 패스는 보정된 기하를 읽는다)
```

HRBF 는 3D 텍스처로 굽지 않고 **해석적으로** 평가한다 (정점당 부위 ≤3 × 샘플 ≤100 × 반복 8 ≈ 수천 flop;
77k 정점에서 수 GFLOP/프레임, Apple GPU 에서 ms 단위). 정확한 C² 장과 정확한 그라디언트를 얻고,
텍스처 보간 때문에 생기는 셀 경계 그라디언트 꺾임이 없다.

### 6.3 합성 연산자의 해석적 근사

논문은 바이하모닉 128³ LUT 를 쓴다. 우리는 프로파일 제어점을 재현하는 닫힌 식을 썼다. m = max(f₁,f₂),
s = min(f₁,f₂), ρ = s/m:

```
g = m + A · d(α) · h(ρ) · w(m),    h(ρ) = ρ(2−ρ),   w(m) = 4m(1−m)
d(α) = smoothstep(BulgeStart, BulgeFull, α),   α = ∠(∇f₁, ∇f₂)
```

A = 0.1 에서 (0.15,0.45): Δ = 0.1·0.555·0.99 ≈ 0.055 (논문 0.05), (0.39,0.40): 0.1·0.999·0.96 ≈ 0.096
(논문 0.10). 대각선(ρ=1)에서 h 의 기울기 부호가 바뀌어 접촉선의 꺾임이 유지된다 — 즉 논문처럼 접촉선은
남고 양 옆만 부푼다. 축(s=0)에서 g=m 이므로 경계조건 g(f₁,0)=f₁ 을 만족한다. 그라디언트는 ∂g/∂m ∇m +
∂g/∂s ∇s 로 정확히 전파 (d(α) 는 Gourmel 과 같이 국소 상수 취급).

엄지 CMC(손바닥–thumb_01)는 합집합, 나머지 모든 손가락 관절(MCP 포함)은 bulge-in-contact.

### 6.5 기존 패스와의 관계

- VolumeBulge(1/J)·캡슐 접촉(bContactBulge)은 이제 implicit 결과 위에서 동작한다. 접촉·롤업은 implicit 이
  담당하므로 캡슐 접촉은 끄고, VolumeBulge 는 미세 보강으로만 둔다 (중복 부풀림 방지).
- 주름 그래프·장력 셰이딩은 변형률을 implicit-보정된 기하에서 계산하므로, 접촉선에 모인 정점의 압축이
  그대로 주름 게이트로 들어간다.
- 비율(FPianoHandProportions)은 뼈 변환에 스케일로 들어가므로 HRBF 장도 같이 스케일된다 (LBS 초기해 +
  스케일된 장 → 정점은 스케일된 등위면으로 수렴).

논문대로 "전부 투영"하면 MetaHuman 손에서는 세 가지가 깨졌고, 각각 디버그 패스(정점색 = 정지/이동량/수렴)로
원인을 좁혀 아래처럼 바꿨다. 모두 `Docs/images/skin_v6_*` 비교 이미지와 함께 §1-O 에 정리.

| 증상 | 원인 (디버그로 확인) | 조치 |
|---|---|---|
| 휴지 자세·손등 MCP 띠의 울퉁불퉁한 융기 | bulge 컨트롤러가 손등에서도 켜짐: 손바닥/지골 HRBF 의 그라디언트 각이 굽히지 않아도 20~40° | 실제 관절 굽힘각 게이트 + 뼈 축 기준 "접힘 안쪽" 반경 판정(FoldSide); 기본 bulge 0 |

필요하다.

## 8. 논문의 손 모델은 무엇이었나 (2026-10-15 조사)

- 2013 논문·학위논문 그림 1.2: "a hand model composed of **31,750 vertices**", 표 4.1: **21 bones** (손 + 중수골 5 + 지골 15),
  HRBF 저장 10.5 MB, 단일 관절 35 fps. 영상 4:03 프레임(사용자가 준 사진)이 이 모델이다.
- **출처는 어디에도 밝혀져 있지 않다.** 프로젝트 페이지 감사 표기는 Juna(Rogério Perdiz), Dana·Carl(Mixamo),
  Armadillo(Stanford)뿐이고 손은 없다. 두 논문의 Acknowledgments 에도 없다. 공개 코드(원 연구 코드의 GitHub
  미러 `zewt/maya-implicit-skinning`, GPL3)에는 메쉬가 한 장도 없고, IRIT 의 "hand 포함 데모(2018, beta, coming
  soon)"는 공개되지 않았다. 즉 **같은 모델을 구할 방법은 없다.**
- 영상의 손은 텍스처 없이 단색 피부 셰이딩(미세 노멀 없음)으로 렌더됐고, 주름은 메쉬에 **조각된 것**(손가락 관절의
  접힘선이 지오메트리에 있음)이다. 우리 MetaHuman 손(77k 정점 PN 테셀레이션)은 해상도·텍스처 면에서 더 높으므로
  모델을 바꿀 이유는 없고, 차이는 (1) 관절 접힘·롤업 기하(이제 Implicit Skinning + 등쪽 gather 로 처리), (2) 주름의
  "조각된" 느낌(우리는 셰이더 라인) 두 가지다. 그래서 2 를 기하로 옮기는 쪽(§1-O, Phase 9 dorsal gather)으로 간다.
