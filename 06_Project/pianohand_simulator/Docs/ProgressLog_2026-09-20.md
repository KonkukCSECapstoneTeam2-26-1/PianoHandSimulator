디버깅 뷰로 확인하여 실제 수치가 의도대로 나오는지 검증함.

# 활동 정리 — 2026-10-14

**주요 활동**

Implicit Skinning(Vaillant et al. 2013) 원논문·2014 Elastic·학위논문을 원문으로 분석해 `Docs/ImplicitSkinning_Study.md`
에 원리를 정리하고, 디포머에 그대로 구현(Phase 8).

**세부 내용**

뼈 부위별 Hermite RBF(φ=r³, 값+법선 제약, 클로저 점, 컴팩트 리매핑 tr) 피팅을 CPU 에서 1회 수행하고, GPU 에서
LBS/DQS 초기 자세의 각 정점을 자기 rest 등위값으로 Newton 투영(σ 0.35, 접촉면 55° 정지), MVC 접선 완화,
접촉 마스크 확산 + 국소 라플라시안을 돌린다. 합성은 합집합 + gradient-based bulge-in-contact(해석적 근사,
논문 프로파일 제어점 재현) 에 실제 관절 굽힘각 게이트를 추가. 이후 변형률/주름/디테일 패스는 보정된 기하를 읽는다.
