# 활동 정리 — 2026-09-20

**주요 활동**

손 메시 적용과 테셀레이션을 통한 고밀도화, 텐션 구동, 피부 셰이딩

**세부 내용**

손 메시에 PN 테셀레이션을 적용해 3,239 → 93,725 정점으로 고밀도화하고, 그 위에 HLSL 셰이더로
피부 조직 주름 표현을 진행함. 주름의 발생 정도는 텐션맵을 기반으로 조절하여, 관절이 굽을수록
해당 부위의 주름이 깊어지도록 구성함. 각 관절별 즉 텐션이 발생하는 지점별로 주름과 텐션을
디버깅 뷰로 확인하여 실제 수치가 의도대로 나오는지 검증함.

**향후 활동**

손바닥 접힘선 추가, 마디별 주름 생성 양식 조절 진행
