# 2. 한승현 — IK (지난번 표가 깨져서 못 읽은 것)

보내준 값은 다 반영했다. 아래 넷만 **표 말고 그냥 줄글로** 다시 적어 주면 된다.

1. `complex_test` 의 **반복 평균 / 반복 최대**
2. `v2_test` 의 **반복 최대**
3. `complex_test` 의 **관절 제한 비율** (엄지 / 검지 / 중지 / 약지 / 소지)
4. 설계서 5.1 class 표에 넣을 항목 — `KeyLayout(건반 흑백 여…` 에서 **뒷부분이 잘렸다**

예시처럼 한 줄씩이면 충분하다.

```
complex_test 반복: 평균 30.4, 최대 40
v2_test 반복 최대: 40
complex_test 관절 제한: 엄지 85 / 검지 95 / 중지 100 / 약지 100 / 소지 93
KeyLayout: 건반 흑백 여부와 좌표를 들고 있는 ...
```

> **확인 하나.** 요(yaw)의 부호(+ = 새끼 쪽)는 운지 엔진 코드를 보고 추론한 것이라고 했는데,
> 내가 엔진 쪽에서 맞춰 보면 되니 지금은 그냥 둬도 된다. 발표에서는 "확인 필요"로 말한다.

# 5. 숫자를 말할 때 조심할 것

측정값이 들어오면서 **그대로 읽으면 틀리게 전달되는 것**이 세 개 생겼다.

| 수치 | 이렇게 말하면 안 된다 | 이렇게 말한다 |
|---|---|---|
| IK 수렴 실패 60.7% | "거의 다 왔다" | 허용 오차 0.01 은 IK 내부 단위(≈0.05 cm)다. **미수렴 풀이의 남은 오차 중앙값이 1.4 cm** 다 |
| 손목 각도 유실 | "롤을 반영하면 해결된다" | 롤 단독은 효과 없었다. **요+롤을 같이 넣어야** 엄지–흑건 오차가 1.54 → 1.10 cm 로 줄었다 |
| Flesh 손끝 어긋남 | "지연이 아니라 형태 차이다" | **둘 다였다.** 정지에 가까울 때는 형태 차이(0.2~0.7 cm), 10 cm/s 이상이면 약 한 프레임 지연(1.3~4.6 cm) |

셋 다 처음 추정이 절반만 맞았던 것이고, 슬라이드와 문서에는 이미 고쳐 놨다.
