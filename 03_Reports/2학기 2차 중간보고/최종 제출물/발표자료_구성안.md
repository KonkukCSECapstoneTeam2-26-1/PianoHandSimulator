## 2. 운지법 (정근녕)

### 슬라이드 4 — 모듈 역할과 파이프라인
- MIDI → 파싱 → 손 분리 → 화음 그룹화 → DP → 손목 물리 → 점유 산출 → JSON/CSV
- *(자료: `results/report_imgs/fig1_pipeline.png`)*

### 슬라이드 5 — 핵심 문제: 제약을 거는 단위
2학기 작업의 중심 내용. 그림 한 장으로 설명한다.

- 물리 제약(손 범위·손가락 유일성·순서)은 **시간상의 한 순간**에 성립해야 한다
- 그런데 엔진은 **화음 단위**로 검사하고 있었다
- 화음은 시간을 분할하지 않는다 — 지속음이 다음 화음까지 걸치고, 서로 다른 화음이 같은 순간에 겹친다
- 같은 데이터에서 화음 단위 위반 3건 vs 순간 단위 위반 2,552건

*(그림 필요: 화음 묶음과 시간축 점유 구간을 나란히 보여주는 도식 — 미제작)*

### 슬라이드 6 — 소리 지속 ≠ 손가락 점유
- MIDI의 `note_off` 는 페달로 늘어난 **소리**의 끝이지 손가락이 떨어진 시점이 아니다
- 드뷔시 '달빛': 페달이 곡의 76.7% 동안 눌려 있고, 손가락 충돌 111건 중 97건(87%)이 페달 구간
- `key_hold_ms` 신설 → 최대 중첩 3,000 ms → 0 ms
- **IK가 `duration_ms` 로 건반을 떼면 한 손가락이 두 건반을 동시에 누른다**

### 슬라이드 7 — 결과
| 항목 | 수치 |
|---|---|
| 처리 곡 수 | 21곡 (실곡 13 + 기준 8) |
| 물리 제약 위반 | **0건** |
| 타이밍 오차 | 0.000 ms |
| 음표 보존율 | 85.2% |
| 처리 시간 | 21곡 17.8초 |

- *(자료: `fig2_finger_dist.png`, `fig3_piano_roll.png`, `fig4_wrist_yaw.png`)*

### 슬라이드 8 — 검증 방법
- 게임 음악 MIDI는 애초에 두 손으로 칠 수 없는 구간이 많다 → 위반이 엔진 탓인지 입력 탓인지 구분 불가
- **연주 가능함이 보장된 기준 입력 8곡**을 생성해, 엔진을 거치지 않고 따로 검증
- 측정 결과 위반 시점의 81.6%가 애초에 연주 불가능한 구간
- 회귀 테스트 5종

## 3. IK (한승현)

### 슬라이드 9 — 모듈 역할
- 운지법 결과 → 관절 각도 시퀀스
- 오프라인 사전 계산. 수렴 속도보다 정확도 우선

### 슬라이드 10 — Weighted DLS
- 수식 `Δθ = W⁻¹Jᵀ(J W⁻¹Jᵀ + λ²I)⁻¹Δe`
- 관절 한계 근접 시 가중치를 낮춰 부드럽게 감속
- 반복 40회, 허용 오차 0.01
- ( ) 손목 아치형 궤적 (베지어)

### 슬라이드 11 — 건반 모델 연동
- 실제 비율 건반에 양손 10손가락 타건
- 흰 건반 / 검은 건반 구분
- *(자료: `KakaoTalk_20261028_173251429.mp4` 또는 `KakaoTalk_20261029_*.mp4` — 어느 영상이 IK인지 확인 필요)*

### 슬라이드 12 — 결과와 한계
- ( ) 손끝-건반 오차, 수렴 반복 수
- 알려진 한계: 마디 길이를 MetaHuman 실측값으로 바꾼 뒤 소지 오차 35% → 57% 증가
- 향후: UE5 Animation 연동

## 4. GPU 스키닝 (이수민)

### 슬라이드 13 — 왜 커스텀 스키닝인가
- 엔진 기본 GPU 스키닝은 정점을 옮기기만 하고 표면 신장률을 계산하지 않는다 → 주름이 생기지 않는다
- 1학기: SVE 포스트프로세스로 가능성 검증 → 2학기: 정점 처리 단계로 전환

### 슬라이드 14 — 6‑Pass 파이프라인
- `UMeshDeformer` 상속, 컴퓨트 셰이더 6개
- Deform → Tension Accumulate/Resolve → Detail Displace → Normal Accumulate/Resolve

### 슬라이드 15 — 텐션 계산
- 변의 신장률을 atomic int 고정소수점으로 누적
- 부피 보존 `1/λ²` (추정값)

### 슬라이드 16 — 손등과 손바닥은 반대로 동작한다
- 주름 생성 조건이 반대 → 이중 게이트
- 이력 주름: 폈다 놓은 직후에도 주름이 남음 (감쇠 약 0.9초)
- *(자료: `각종 손 캡쳐/`)*

### 슬라이드 17 — 결과와 한계
- *(자료: 최종 결과 스틸)*
- 한계: 손바닥 접힘선 미출력, 손목 절단면 노멀 거침, 성능 미측정

## 6. 통합과 마무리

### 슬라이드 22 — 모듈 간 인터페이스
- A: 운지법 → IK (JSON/CSV)
- B: IK → Skinning (AnimSequence 30 FPS)
- C: Flesh → GPU 스키닝 (정점 버퍼) — **미구현**
- D: Skinning → Main
- **단위는 mm, UE5는 cm → 소비 측에서 ÷10**

### 슬라이드 23 — 공유 상수
2학기에 실제로 겪은 문제를 보여주는 장.

- 각 파트가 같은 수치를 따로 들고 있었다
- 흑건 앞뒤 위치가 건반 형상에서 도출될 수 없는 값(+3.0 cm)으로 적혀 있었다 → +55 mm 정정
- IK가 참조할 흑건 상면 높이는 명세에 **정의 자체가 없었다** → 12.5 mm 신규
- 백건 폭을 반올림하면 88키 끝에서 1.5 mm 누적 오차
- `shared_constants.py` 단일 출처로 통합
